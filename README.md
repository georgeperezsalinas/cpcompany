# Sitio web CP Company S.A.C.

Sitio corporativo estático listo para publicarse en **cpcompanysac.com**.

## Contenido
- Inicio
- Empresa (misión, visión, ámbito)
- Servicios (construcción, ingeniería, agrícola, minería)
- Experiencia (consultoría y obras del curriculum 09.2026)
- Equipo
- Contacto

## Publicación
1. Suba la carpeta completa al hosting del dominio `cpcompanysac.com`.
2. Defina `index.html` como documento de inicio.
3. Conecte el formulario de contacto a un backend o a Formspree / Netlify Forms / correo SMTP.
4. Agregue certificado HTTPS.

## Personalización recomendada
- Reemplazar el isotipo "CP" por el logotipo oficial.
- Incorporar fotografías de obra propias.
- Añadir RUC y datos SUNAT si se requiere en pie de página.
